# Quick Product Manager

A WordPress plugin for WooCommerce stores that puts your entire product catalog in one admin screen, so you can update prices and stock without opening each product edit page.

## Features

- **Single admin menu** — View all WooCommerce products in one list.
- **Quick edits** — Change product price and inventory from the same screen.
- **Less clicking** — No need to open every product page in the dashboard.

## Requirements

- WordPress 5.8 or later
- [WooCommerce](https://woocommerce.com/) active on the site
- PHP 7.4 or later (recommended: PHP 8.0+)

## Installation

1. Download or clone this repository into `wp-content/plugins/quick-product-manager/`.
2. In **WordPress Admin → Plugins**, activate **Quick Product Manager**.
3. Open the new menu item in the admin sidebar to manage products.
